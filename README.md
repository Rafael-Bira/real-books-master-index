# MASTER INDEX

This indexes cover several of the Real and Fake Books, which are listed below. They were made as an improvement of the older Master Index PDF, so now you can easily search songs and quickly navigate through different files.

## Instructions

Simply download the corresponding `Index` file and put it into the same folder where the other PDFs are located, then open it from your browser.

> [!IMPORTANT]
> It's mandatory that the PDF files have the specified number of pages and **exact** names (including lower and uppercase).
